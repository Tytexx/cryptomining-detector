# Cryptomining Detector

A live system monitor that detects cryptomining activity using a trained Random Forest model and rule-based network scanning, with optional AI-generated alerts via the Gemini API.

---

## How it works

1. Collects 15 system metrics every 5 seconds using `psutil`
2. Feeds them into a pre-trained Random Forest model to get a mining probability score
3. Simultaneously scans open network connections for known mining pool ports
4. If a threat is detected, optionally generates a plain-language alert using Gemini

---

## Files

| File | Description |
|------|-------------|
| `train_model.py` | Loads the dataset, drops leaky features, trains Decision Tree and Random Forest models, saves `cryptomining_detector.pkl` |
| `monitor.py` | Live monitor — collects metrics, runs inference, scans network, displays results |
| `cryptomining_detector.pkl` | Trained Random Forest model (generated by `train_model.py`) |
| `requirements.txt` | Python dependencies |

## Setup

### 1. Clone the repo

```bash
git clone <repo-url>
cd <repo-folder>
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Gemini API (optional)

Create a `.env` file in the project root:

```
GEMINI_API_KEY=your_key_here
```

The monitor works without this, it falls back to a static alert message if no key is set.

---

## Usage

### Train the model

Required only once, or when retraining on new data:

```bash
python train_model.py
```

Expects two CSV files in the same directory:
- `final-normal-data-set.csv`
- `final-anormal-data-set.csv`

Outputs `cryptomining_detector.pkl` and two charts.

### Run the live monitor

```bash
python monitor.py
```

Press `Ctrl+C` to stop.

## Features used by the model

| Category | Feature | Description |
|----------|---------|-------------|
| CPU | `cpu_iowait` | CPU time waiting for disk |
| CPU | `cpu_nice` | CPU time on low priority processes |
| CPU | `cpu_system` | CPU time on kernel/OS operations |
| CPU | `cpu_total` | Overall CPU usage percentage |
| CPU | `cpu_user` | CPU time on user processes |
| Load | `load_cpucore` | Number of CPU cores |
| Load | `load_min1` | 1-minute load average |
| Load | `load_min5` | 5-minute load average |
| Load | `load_min15` | 15-minute load average |
| Process | `processcount_running` | Currently active processes |
| Process | `processcount_sleeping` | Sleeping processes |
| Process | `processcount_thread` | Total thread count |
| Process | `processcount_total` | Total process count |
| Disk | `diskio_sda_write_bytes` | Rate of bytes written to disk per second |
| Network | `network_lo_rx` | Bytes received on loopback interface |

## Detection methods

**ML-based**: The Random Forest model outputs a probability score. Thresholds:
- ≥ 80% → High probability alert
- ≥ 60% → Possible activity warning
- < 60% → No threat

**Rule-based**: Scans open TCP connections against a list of known mining pool ports (3333, 4444, 8333, 14444, and others). If a match is found, the responsible process name is retrieved and displayed.
